```python
"""时间解析与格式化（§5.1：时间统一 `YYYY-MM-DD HH:mm:ss`）。"""
from datetime import datetime, time

TIME_FORMAT = "%Y-%m-%d %H:%M:%S"


def parse_time(s: str) -> datetime:
    """解析 `YYYY-MM-DD HH:mm:ss`，失败抛 ValueError。"""
    try:
        return datetime.strptime(s, TIME_FORMAT)
    except (ValueError, TypeError):
        raise ValueError("时间格式应为 YYYY-MM-DD HH:mm:ss")


def format_time(dt: datetime | None) -> str | None:
    return dt.strftime(TIME_FORMAT) if dt else None


def format_clock(t: time | None) -> str | None:
    return t.strftime("%H:%M:%S") if t else None
```

**你的判断是对的，别写替身。** 关键在 `except (ValueError, TypeError)` —— 它把 `TypeError`
**也**收敛成 `ValueError` 了。所以这个函数对外的契约是「只抛 `ValueError`」，
`create_order` 里 `except ValueError as exc: return _fail("invalid_param", str(exc))`
才成立。

如果写个朴素的 `datetime.strptime(s, FMT)` 替身，模型传 `None` 或数字时 `TypeError`
会直接漏出去，`invalid_param` 当场变 500。**照抄这 21 行。**

from enum import IntEnum
from typing import Dict, Set


class OrderStatus(IntEnum):
    PENDING = 1      # 待确认
    CONFIRMED = 2    # 已确认
    CANCELLED = 3    # 已取消
    COMPLETED = 4    # 已完成


# 合法流转表：from -> {to ...}
TRANSITIONS: Dict[int, Set[int]] = {
    OrderStatus.PENDING: {OrderStatus.CONFIRMED, OrderStatus.CANCELLED},
    OrderStatus.CONFIRMED: {OrderStatus.COMPLETED, OrderStatus.CANCELLED},
    OrderStatus.COMPLETED: set(),   # 终态
    OrderStatus.CANCELLED: set(),   # 终态
}


class IllegalTransitionError(Exception):
    pass


def can_transition(from_status: int, to_status: OrderStatus) -> bool:
    """校验 from -> to 是否合法。"""

出处是 `docs/api.md` §7.5「自动化护栏」（第 302 行）：**「`backend/tests/module3/test_order_service.py`

它钉死的是**六项**，不只是参数名：

```python
FROZEN_PARAMS = [
    "user_id", "space_id", "start_time", "end_time",
    "device_ids", "agent_request", "agent_trace", "order_status",
]
```

| 断言 | 含义 |
|---|---|
| `[p.name for p in params] == FROZEN_PARAMS` | 参数名与**顺序**冻结（顺序变了也红） |
| `p.kind is Parameter.KEYWORD_ONLY` | 位置传参一律拒绝 —— 防止日后在中间插参数时静默错位 |
| `"db" not in params` | 签名里**不得出现 `db`**：Tool 拿不到 `AsyncSession`（§7.4），会话由服务层自管（§5.5） |
| 每个参数有类型标注 | 冻结期不允许再改 |
| 默认值只允许出现在后四个 | 前四个 `user_id`/`space_id`/`start_time`/`end_time` 必填 |

所以你那份**必须原样匹配这个签名**，否则这六项里任意一项都会红 ——
这也正是你要的「替换得对不对」的判据。
