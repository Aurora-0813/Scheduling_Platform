# 语音模块 · 小程序端集成说明（给移动端 蔡玉礼）

技术栈：Uni-app（HBuilderX 4.24），微信小程序。

## 文件清单

| 文件 | 说明 |
| --- | --- |
| `pages/voice/record.vue` | 录音页面：点按钮录音、自动上传、显示识别结果 |
| `utils/voiceApi.js` | 接口封装：上传录音、口语格式化，后端地址在此文件顶部改 |

## 第 1 步：注册页面（pages.json）

```json
{
  "path": "pages/voice/record",
  "style": { "navigationBarTitleText": "语音预约" }
}
```

## 第 2 步：麦克风权限（manifest.json -> mp-weixin）

```json
"mp-weixin": {
  "permission": {
    "scope.record": {
      "desc": "用于语音预约，将你说的话识别成文字"
    }
  }
}
```

## 第 3 步：后端地址

`utils/voiceApi.js` 顶部 `BASE_URL`：开发者工具用 `http://127.0.0.1:8000`（勾选不校验合法域名）；真机用电脑局域网 IP；上线用 https 域名。

## 录音参数（已与后端对齐，勿改）

wav 格式、16000 采样率、单声道、最长 60 秒。

## 对应后端接口

- `POST /api/v1/voice/asr`：FormData 字段 `file` → `{ code:200, data:{ text } }`
- `POST /api/v1/voice/format`：`{ rawText }` → `{ code:200, data:{ formattedText, keywords } }`
